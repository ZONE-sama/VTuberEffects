VTUBER EFFECTS FOR OBS
Version 0.15.8


OVERVIEW

VTuber Effects is an OBS video filter for transparent avatar captures. It can
make an avatar inherit the general color and brightness of a game, video, scene,
or source group without displaying recognizable details from that source.

The filter also includes directional rim lighting, protected emissive colors,
emissive bloom, a drop shadow, and an outer glow.

This compatibility build targets OBS Studio 29.0.2 and later.


INSTALLATION

Close OBS before installing or replacing the plugin.

Copy the contents of the vtuber-effects folder into the OBS Studio installation
folder so the files are placed as follows:

obs-plugins\64bit\vtuber-effects.dll
data\obs-plugins\vtuber-effects\effects
data\obs-plugins\vtuber-effects\images
data\obs-plugins\vtuber-effects\locale

The standard OBS Studio installation folder on Windows is:

C:\Program Files\obs-studio

Restart OBS after copying the files.


BASIC SETUP

1. Add the transparent avatar capture to an OBS scene.

2. Open the avatar source's Filters window.

3. Add VTuber Effects under Effect Filters.

4. Select an Environment source or group.

The environment should be the full-frame game, video, scene, or source group
behind the avatar. It should use the same aspect ratio as the avatar capture.
Do not select a scene or group that contains the filtered avatar itself.

A red warning is displayed when no environment source is selected.


DIAGNOSTIC VIEW

Diagnostic View is directly below the environment selector. It displays one
processing stage at a time to help with setup and troubleshooting.

Final output
Displays the completed effect.

Blurred environment
Displays the smooth color texture used by ambient and rim lighting.

Ambient pass
Displays ambient lighting by itself.

Rim pass
Displays rim lighting by itself.

Protected color mask
Displays the pixels recognized as protected light colors.

Original capture
Displays the unmodified avatar source.

Drop shadow pass
Displays the drop shadow with transparent surroundings.

Outer glow pass
Displays the outer glow with transparent surroundings.

Emissive bloom pass
Displays bloom generated by protected colors with transparent surroundings.

Return Diagnostic View to Final output before streaming or recording.


AMBIENT LIGHTING

Ambient Lighting covers the visible avatar with a heavily blurred version of
the selected environment. The avatar inherits broad scene colors and brightness
without recognizable background details appearing on it.

Enable ambient lighting
Turns ambient lighting on or off.

Base brightness
Sets the minimum brightness retained before environment color is applied.

Environment color amount
Controls how strongly the environment colors affect the avatar.

Environment blur radius
Controls how broadly the environment is averaged. Higher values produce
smoother and more generalized lighting.

Default values:

Enabled
Base brightness: 0.20
Environment color amount: 2.00
Environment blur radius: 330 pixels


AUTOMATIC EXPOSURE COMPENSATION

This section controls the brightness and color intensity of the sampled
environment before it is used by Ambient Lighting and Rim Lighting.

Enable automatic exposure compensation
Adjusts unusually bright or dark environment samples toward the target
brightness.

Target environment brightness
Sets the brightness that automatic exposure attempts to maintain.

Exposure compensation strength
Controls how strongly automatic exposure corrects the environment. A value of
0 applies no correction. A value of 1 applies the full calculated correction.

Minimum exposure multiplier
Limits how much a bright environment may be darkened. Lower values permit
stronger darkening.

Maximum exposure multiplier
Limits how much a dark environment may be brightened.

Environment saturation
Controls the overall color saturation used by ambient and rim lighting. A value
of 1 leaves saturation unchanged. A value of 0 produces grayscale lighting.

Environment vibrance
Adjusts muted colors more strongly than colors that are already saturated.

Environment contrast
Controls contrast in the environment colors before they are used as lighting.
A value of 1 leaves contrast unchanged.

Maximum color intensity
Caps the strongest processed color channel while preserving its hue. Lower this
value if intense scenes overpower the avatar.

Default values:

Automatic exposure compensation: Disabled
Target environment brightness: 0.45
Exposure compensation strength: 1.00
Minimum exposure multiplier: 0.35
Maximum exposure multiplier: 2.00
Environment saturation: 1.00
Environment vibrance: 0.00
Environment contrast: 1.00
Maximum color intensity: 1.00


RIM LIGHTING

Rim Lighting creates a soft directional band just inside the avatar's edge.
The band is colored by the selected environment.

Enable rim lighting
Turns rim lighting on or off.

Rim brightness
Controls the overall intensity of the rim.

Rim environment color amount
Controls the strength of the environment color on the rim.

Rim layer base brightness
Sets the base brightness used by Masked Duplicate blend mode.

Rim blend mode
Selects how the rim is combined with the avatar.

Additive produces strong light by adding brightness.

Screen produces softer brightening and retains more detail.

Normal Mix blends directly toward the rim color.

Masked Duplicate reveals an environment-lit duplicate through the rim mask.
This most closely resembles a traditional duplicated-source workflow.

Rim width
Controls how far the rim extends inward from the avatar's edge.

Rim softness
Controls the transition between the rim and the rest of the avatar.

Rim mask scale
Scales the silhouette used to calculate the rim.

Horizontal offset
Moves the rim mask left or right.

Vertical offset
Moves the rim mask up or down.

Default values:

Enabled
Rim brightness: 0.50
Rim environment color amount: 2.00
Rim layer base brightness: 1.00
Blend mode: Masked Duplicate
Rim width: 25 pixels
Rim softness: 0.75
Rim mask scale: 0.935
Horizontal offset: -25 pixels
Vertical offset: -15 pixels


PROTECTED LIGHT COLORS AND EMISSIVE BLOOM

Protected Light Colors preserve selected colors from the original avatar after
lighting is applied. This keeps emissive eyes, lamps, displays, and similar
features clear and unchanged.

Enable protected light colors
Turns protected-color restoration on or off.

Protected color count
Sets the number of active protected-color entries, from 0 to 10.

Color
Selects the emissive source color to preserve.

Color tolerance
Controls how different a pixel may be from the selected color and still match.

Match softness
Softens the transition between matched and unmatched pixels.

Minimum saturation
Rejects neutral or weakly colored pixels.

Minimum brightness
Rejects dark pixels with a similar hue.

Protection strength
Controls how strongly matching pixels are restored to their original
appearance.

Enable protected-color bloom
Creates a colored halo from pixels matched by Protected Light Colors.

Emissive bloom brightness
Controls the intensity of the emitted bloom.

Emissive bloom radius
Controls how far the bloom spreads from matching pixels.

Bloom uses the original matching pixel color. Red eyes produce red bloom, while
green indicators produce green bloom.

The first protected color defaults to red, FF0000. Every protected-color entry
has independent matching controls.


DROP SHADOW

Drop Shadow places a blurred and offset copy of the avatar silhouette behind
the avatar.

Enable drop shadow
Turns the drop shadow on or off.

Shadow color
Sets the color of the shadow.

Shadow opacity
Controls the visibility of the shadow.

Shadow blur radius
Controls the softness and spread of the shadow.

Horizontal shadow offset
Moves the shadow left or right.

Vertical shadow offset
Moves the shadow up or down.

Default values:

Disabled
Shadow color: Black
Shadow opacity: 0.65
Shadow blur radius: 24 pixels
Horizontal offset: 12 pixels
Vertical offset: 12 pixels


OUTER GLOW

Outer Glow creates a smooth fixed-color halo outside the avatar. It is
independent of environment lighting and the drop shadow.

Enable outer glow
Turns the outer glow on or off.

Glow color
Sets the color of the halo.

Glow blend mode
Selects how the halo combines with the scene behind the avatar.

Additive produces the strongest emitted-light appearance.

Screen produces a softer lightening effect.

Normal produces a conventional translucent colored halo.

Glow brightness
Controls the intensity and opacity of the glow.

Glow width
Controls how far the glow extends beyond the avatar.

Default values:

Disabled
Glow color: White
Blend mode: Additive
Glow brightness: 1.00
Glow width: 30 pixels


IMPORTING AND EXPORTING SETTINGS

The Import and Export controls are at the bottom of the filter settings.

Export settings opens a file browser and saves the current effect controls to
a JSON text file.

Import settings opens a file browser and loads a previously exported JSON file.

Preset files include Ambient Lighting, Automatic Exposure Compensation, Rim
Lighting, Protected Light Colors, Emissive Bloom, Drop Shadow, and Outer Glow.

Preset files do not include the Environment source or Diagnostic View because
source names and scene layouts differ between OBS installations.


RESET BUTTONS

Each effect section has its own reset button. A reset only affects that section.
It does not change the environment selection, diagnostic view, or other
effects.


FILTER ORDER

OBS processes filters from top to bottom.

Filters above VTuber Effects modify the avatar before these effects are
calculated.

Filters below VTuber Effects modify the completed lighting, shadow, bloom, and
glow.


PERFORMANCE

Large blur and bloom values require more GPU work, especially with
high-resolution sources.

If performance is lower than expected:

Reduce the Environment blur radius.
Reduce Rim width.
Reduce Emissive bloom radius.
Reduce Glow width.
Reduce Shadow blur radius.
Disable effects that are not being used.


TROUBLESHOOTING

VTuber Effects is not listed in OBS

Confirm that vtuber-effects.dll is in:

obs-plugins\64bit

Confirm that the effects, images, and locale folders are in:

data\obs-plugins\vtuber-effects


Environment lighting does not appear

Select an Environment source or group.
Confirm that the selected source is visible and producing video.
Confirm that Ambient Lighting or Rim Lighting is enabled.
Do not select a scene or group containing the filtered avatar.


Protected colors match too much of the avatar

Lower that color entry's tolerance or softness.
Raise its minimum saturation or minimum brightness.
